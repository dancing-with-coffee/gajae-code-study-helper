# wiki-ingest — 새 자료를 위키에 넣기

AGENTS.md의 규칙을 그대로 따른다. 특히 `raw/`는 절대 수정하지 않는다.

## 순서

1. **새 자료 찾기**: `raw/`의 파일 목록과 `wiki/sources/`의 파일 목록을 비교한다. `wiki/sources/`에 같은 이름이 없는 raw 파일이 새 자료다. 새 자료가 없으면 "새 자료가 없습니다"라고 말하고 끝낸다.
2. **읽기**: 새 raw 파일을 처음부터 끝까지 읽는다. 맨 위 프런트매터의 `title`, `source_url`, `published`를 확인한다.
3. **요약 페이지 만들기**: `wiki/sources/<raw 파일 이름>`을 만든다. 형식:
   - `# <원제>`
   - 원문 정보 목록: 원문 URL, 게시일, raw 파일 링크(`../../raw/<파일>`)
   - `## 한 줄 요약`
   - `## 핵심 내용` (5~8개 항목, 각 항목은 원문에 있는 내용만)
   - `## 이 자료가 다루는 개념` (개념 페이지 링크 목록)
4. **개념 페이지 만들거나 고치기**: 이 자료의 핵심 개념 2~4개를 고른다.
   - 이미 `wiki/concepts/`에 있는 개념이면, 새 내용을 해당 섹션에 덧붙이고 `## 출처`에 이 raw 파일을 추가한다. 기존 내용과 부딪히면 지우지 말고 "자료마다 다르게 말한다"고 적는다.
   - 없는 개념이면 AGENTS.md의 개념 페이지 형식으로 새로 만든다.
   - 모든 문단 끝에 출처 링크를 단다.
5. **목차 갱신**: `wiki/index.md`의 `## 개념`과 `## 원본 요약` 목록에 새 페이지를 `- [제목](경로) — 한 줄 요약` 형식으로 추가한다.
6. **기록**: `wiki/log.md` 맨 아래에 `- [오늘 날짜] ingest | <원제> 추가 | <바뀐 페이지 목록>`을 추가한다.
7. **보고**: 새로 만든 페이지와 고친 페이지를 목록으로 보여준다.
