# wiki-lint — 위키 건강 검진

AGENTS.md의 규칙을 따른다. 이 스킬은 **보고만** 한다. 사용자가 "고쳐줘"라고 하기 전에는 파일을 고치지 않는다.

## 순서

1. **기계 검사**: 터미널에서 `bun run lint`를 실행한다. 이 명령은 아래를 자동으로 검사한다.
   - 깨진 링크(없는 파일을 가리키는 링크)
   - 출처 섹션이 없거나 raw 링크가 없는 개념 페이지
   - 출처 링크가 하나도 없는 문단
   - 고아 페이지(index.md나 다른 페이지 어디에서도 링크되지 않는 페이지)
   - 요약 페이지가 없는 raw 파일
2. **내용 검사**: 개념 페이지들을 읽고 아래를 직접 찾는다. 기계가 못 하는 일이다.
   - 서로 모순되는 설명(같은 개념을 페이지마다 다르게 설명)
   - raw에 없는 내용(출처 링크가 달린 raw 파일을 열어 실제로 그 내용이 있는지 확인)
3. **보고서**: 아래 형식으로 화면에 보여준다.

```
## 위키 검진 보고서 (YYYY-MM-DD)
- 기계 검사: 오류 N개
- 모순: N개
- 근거 없는 내용: N개
### 자세히
- [종류] 파일 — 설명
```

4. `wiki/log.md` 맨 아래에 `- [오늘 날짜] lint | 오류 N개 | 없음`을 추가한다.
