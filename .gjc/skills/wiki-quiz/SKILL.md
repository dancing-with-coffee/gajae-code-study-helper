# wiki-quiz — 개념 퀴즈 풀기

AGENTS.md의 규칙을 따른다. 문제와 해설은 위키와 raw에 있는 내용으로만 만든다.

## 순서

1. `wiki/index.md`를 읽고, `ask` 도구로 "어떤 개념으로 퀴즈를 풀까요?"라고 묻는다. 선택지는 개념 페이지 제목 4개.
2. 고른 개념 페이지와 그 출처 raw 파일을 읽는다.
3. `wiki/quizzes/<개념 파일 이름>`이 이미 있으면 그 문제를 쓴다. 없으면 객관식 3문제(보기 4개, 정답 1개)를 만든다.
4. 한 문제씩 `ask` 도구로 낸다. 질문은 문제 문장, 선택지는 보기 4개.
5. 답을 받을 때마다 맞았는지 알려주고 해설을 보여준다. 해설에는 출처 링크를 단다.
6. 3문제가 끝나면 점수(예: 2/3)를 알려준다.
7. 퀴즈 파일을 아래 형식으로 저장한다. 웹 화면이 이 형식을 읽으므로 형식을 바꾸지 않는다.

```
---
concept: <개념 파일 이름, 확장자 없이>
title: <개념 제목>
---

# 퀴즈: <개념 제목>

## 문제 1

<문제 문장>

- A) <보기>
- B) <보기>
- C) <보기>
- D) <보기>

정답: <A~D>

해설: <해설> ([출처](../../raw/<파일>))

## 문제 2
...

## 풀이 기록

- [YYYY-MM-DD] 점수 N/3
```

   이미 있던 파일이면 `## 풀이 기록` 맨 아래에 한 줄만 추가한다.
8. `wiki/log.md` 맨 아래에 `- [오늘 날짜] quiz | <개념 제목> N/3 | wiki/quizzes/<파일>`을 추가한다.
