# wiki-query — 위키를 근거로 질문에 답하기

AGENTS.md의 규칙을 따른다. 답은 AGENTS.md의 "설명 수준"에 맞춘다.

## 순서

1. 질문이 없으면 `ask` 도구로 "무엇이 궁금한가요?"라고 묻는다.
2. `wiki/index.md`를 읽고 질문과 관련된 페이지를 2~4개 고른다.
3. 고른 페이지를 읽는다. 더 자세한 근거가 필요하면 그 페이지의 `## 출처`에 있는 raw 파일을 읽는다.
4. 답한다.
   - 위키에 있는 내용만 쓴다. 위키에 없으면 "위키에 아직 없는 내용입니다"라고 말하고, 어떤 자료를 `raw/`에 넣으면 좋을지 제안한다.
   - 답 끝에 `근거:` 줄을 달고 읽은 위키 페이지 경로를 적는다.
5. 답이 다른 사람에게도 쓸모 있어 보이면 `ask` 도구로 "이 답을 위키에 저장할까요?"(예 / 아니오)라고 묻는다.
   - "예"면 `wiki/concepts/`에 질문을 제목으로 한 페이지를 개념 페이지 형식으로 저장하고, `wiki/index.md`에 추가한다.
6. `wiki/log.md` 맨 아래에 `- [오늘 날짜] query | <질문 요약> | <저장한 페이지 또는 "저장 안 함">`을 추가한다.
